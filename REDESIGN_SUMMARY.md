## 🎯 Fokus Design

### Typography

- **Heading**: Playfair Display (serif, elegant)
- **Body**: Poppins (sans-serif, modern, readable)
- **Hierarchy**: Jelas dengan size & weight variations

### Color Palette

- **Primary**: #2d4059 (Deep Navy Blue) - Professional & trustworthy
- **Secondary**: #ea5455 (Coral Red) - Energetic & attention-grabbing
- **Accent**: #f07b3f, #ffd460 (Warm tones) - Friendly & inviting
- **Gradients**: Multiple gradient combinations untuk visual interest

### Layout & Grid

- Container max-width dengan proper spacing
- Consistent padding & margins (80px sections)
- Responsive grid dengan proper breakpoints
- Card-based layout dengan proper spacing (g-4)

### Visual Effects

- Box shadows untuk depth
- Border radius untuk modern look (12px-20px)
- Hover transitions (transform, shadow, color)
- Loading animations dengan Intersection Observer
- Smooth scrolling behavior

## 📱 Responsive Design

- ✅ Mobile-first approach
- ✅ Breakpoints: 768px (tablet), 992px (desktop)
- ✅ Hero title scales down on mobile
- ✅ Grid columns stack properly
- ✅ Touch-friendly button sizes
- ✅ Proper spacing on small screens

## 🚀 Performance Optimizations

- ✅ Preconnect untuk Google Fonts & CDN
- ✅ Minimal external dependencies
- ✅ Efficient CSS dengan CSS variables
- ✅ Hardware-accelerated animations (transform, opacity)
